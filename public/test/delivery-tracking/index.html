Test Delivery Tracking

Module de test complet pour le suivi de livraisons en temps réel

Cartographie interactive WebSocket en temps réel Interface responsive

Fonctionnement du système

1. Client

Le client suit sa commande en temps réel, reçoit les notifications de position du livreur et l'ETA.

2. Livreur

Le livreur simule sa livraison, met à jour sa position et change les statuts de livraison.

3. Manager

Le manager supervise toutes les livraisons actives sur un tableau de bord centralisé.

Lancer les simulations

Simulation Client

Interface de suivi pour le client final. Suivez votre commande en temps réel.

  • Suivi temps réel
  • Position du livreur
  • ETA dynamique
  • Historique des événements

Simulation Livreur

Interface pour le livreur. Créez et simulez des livraisons.

  • Création de livraisons
  • Simulation de trajet
  • Contrôle de vitesse
  • Gestion des statuts

Simulation Manager

Tableau de bord de supervision. Vue d'ensemble de toutes les livraisons.

  • Vue globale
  • Supervision temps réel
  • Statistiques
  • Gestion centralisée
Instructions d'utilisation
  1. Démarrez le livreur pour créer une nouvelle livraison
  2. Lancez la simulation de trajet depuis l'interface livreur
  3. Ouvrez le client pour suivre la livraison en temps réel
  4. Surveillez depuis le manager pour avoir une vue d'ensemble
