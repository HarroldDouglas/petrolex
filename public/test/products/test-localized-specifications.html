Test des Spécifications Localisées

Ce test démontre comment les spécifications des produits sont localisées selon la langue de l'utilisateur.

Instructions
  1. Connectez-vous d'abord avec un utilisateur
  2. Sélectionnez un centre de distribution
  3. Les spécifications des produits s'afficheront dans la langue de l'utilisateur
Test en Français

Les spécifications devraient apparaître comme :

  • Capacité : 6.00 L
  • Hauteur : 40.00 cm
  • Poids : 12.50 kg
  • Rayon : 15.00 cm
Test en Anglais

Les spécifications devraient apparaître comme :

  • Capacity : 6.00 L
  • Height : 40.00 cm
  • Weight : 12.50 kg
  • Radius : 15.00 cm
