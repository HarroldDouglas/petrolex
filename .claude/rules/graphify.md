# Graphify

Si un knowledge graph graphify existe dans `graphify-out/` :

- Avant de répondre à une question d'architecture ou de codebase, lire `graphify-out/GRAPH_REPORT.md`
  (god nodes + structure des communautés) plutôt que de fouiller les fichiers bruts.
- Si `graphify-out/wiki/index.md` existe, naviguer dedans en priorité.
- Après avoir modifié des fichiers de code dans la session, régénérer le graphe pour le garder à jour.
